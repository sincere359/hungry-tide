## 1. 主色与主菜单

| | 原版图标（2012） | 本项目菜单 |
|---|---|---|
| 参考 | `ref/ref1.jpg` | `shots/20-public-menu.png` |

**一致**
- 高饱和青绿海水 + 顶部暖白光源，整体明亮、通透

- 本项目菜单为"鲨鱼卡片横向滚动"，原版为单鲨展示 + 商店入口

## 2. Giant Crab Boss

| | 原版（2013） | 本项目 |
|---|---|---|
| 参考 | `ref/ref10.jpg` | `shots/11-boss.png` |

**一致**
- 橄榄绿甲壳 + 红色背部弱点（本项目用发光球替代）
- 左右巨钳、多足、低照度深水
- 巢穴内珊瑚/岩壁包围
- 交互逻辑：闪避钳击 → 弱点暴露 → 冲刺撞击

**差异**
- 原版高模 + 贴图 + 复杂珊瑚；本项目低多边形 + 顶点色/纯色材质
- 本项目增加青/暖双点光源以便移动端识别
- 原版为近景特写，本项目为可战斗的全景机位

## 3. 单地图结构与 HUD

| | 原版 Basic Map（2013） | 本项目游玩画面 |
|---|---|---|
| 参考 | `ref/ref2.jpg` | `shots/02-play.png` |

**一致**
- 单张横向主地图、上方 Drop Point 出生、左端 Boss 巢
- 贝壳/沉没物散布、右上资源与暂停、顶部生命/分数
- 浅滩 → 开阔 → 海沟 → 海床的深度分层

**差异**
- 本项目没有独立地图界面，直接以场景表达分区
- HUD 为顶部三段式（生命/分数/资源），原版为顶部双条 + 左下贝壳
- 本项目 Boost 为右下圆形按钮，原版为底部进度条/点击加速

## 4. 水体层次与 Gold Rush

| | 原版加载图 | 本项目金潮 |
|---|---|---|
| 参考 | `ref/ref4.jpg` | `shots/10-goldrush-natural.png` |

**一致**
- 深蓝→青绿垂直渐变，悬浮颗粒，金色滤镜与金色猎物
- 金潮期间全屏暖色、猎物高亮、节奏加快
- 低照度 Boss 场景与明亮水面形成强对比

**差异**
- 原版体积雾/光柱/高精度贴图；本项目指数雾 + 背景 shader 焦散 + 粒子
- 大幅光柱在移动端观感生硬，已降级移除（README 已注明）
- 本项目金潮为 20 秒固定窗口，原版按鲨鱼不同时长/充能不同

---

## 结论

**达到"神似"的部分**：水色与光照方向、金色 HUD 体系、鲨鱼剪影、Boss 的绿色甲壳/红色弱点、金潮的暖色爆发、单地图左端 Boss 房的空间逻辑。

**明确不追求 1:1 的部分**：原版资源（模型/贴图/音频/字体）、全 3D 自由相机、复杂珊瑚与体积光、后期 live-ops 内容。

**最大差异**：本项目采用 2.5D 侧视 + 低多边形程序化资产，原版为全 3D 高模场景；因此本项目在"氛围与玩法节奏"上对齐，在"材质细节与镜头自由度"上主动降级。
