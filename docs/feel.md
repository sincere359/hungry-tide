# 操控手感对照：经典版 vs Hungry Tide

> 本文件对应验收项「摇杆操控手感与原版对比：转向响应、加速反馈、镜头跟随三项逐一说明差异」。
> 数据来自实现参数与 Android Chrome / Chromium 实测；**iPhone 真机仍需按 README 清单确认**。

---

## 0. 基准差异（先说明）

经典版 2012–2013 的触控是「**手指按住屏幕任意位置拖动 → 鲨鱼朝手指方向转向**，轻点冲刺」，2012 默认还支持倾斜。它没有固定摇杆 UI。
本项目按你的选择实现「**动态虚拟摇杆**」：触点即原点、拖动方向即输入方向。两者都是"手指即方向"，但摇杆有明确的死区与最大行程，转向是**方向 + 力度**，比原版"手指即目标点"更偏载具感。

| 维度 | 原版（调研结论） | 本项目 | 差异判断 |
|---|---|---|---|
| 输入隐喻 | 手指=目标方向（拖动） | 动态摇杆（触点原点，8px 死区，56px 满行程） | 摇杆更可控，但不如原版"指哪游哪"直接 |
| 冲刺 | 轻点屏幕 / 冲刺条 | 右下按钮或第二指按住，46/s 消耗 | 按钮更易发现，但少了"点哪都能冲"的随手感 |
| 相机 | 全 3D 尾随 | 2.5D 侧视尾随 | 本项目无 3D 环绕，构图更稳定但自由度低 |

## 1. 转向响应

**实现参数**
- 摇杆：死区 8 CSS px，最大位移 56 px，力度 = `(len-8)/(56-8)`，限幅 0–1
- 加速度：常规 52 m/s²，冲刺 78 m/s²
- 阻尼：有输入 0.85/s，松手 2.6/s
- 最大速度：9.0（Reef）–14.5（Megalodon）m/s
- 朝向平滑：`heading += Δangle × min(1, dt×10)`，约 63% 响应在 100 ms，95% 在 300 ms
- 逐帧读取 Pointer Events，输入到方向向量**同帧生效**（≤16.7 ms）

**实测**
- Android Chrome（786×268 CSS，DPR 2.75）：`adb input swipe` 向下右拖动 900 ms，鲨鱼由 (0,−26) 移到 (3,−31)，方向正确（下潜），位移约 5.8 m。
- Chromium 844×390：1.2 s 拖动后位移约 10 m，转向无跳变。

**与原版差异**
- 原版是"手指即目标点"，转向半径由鲨鱼速度与阻尼决定；本项目多了一层摇杆死区，**微调更稳、急转略慢**。
- 原版可 3D 改变朝向；本项目只改变侧视平面内的俯仰角，**不会出现"绕到鱼群背后"的 3D 机动**。
- 主观结论：本项目更容易保持直线巡航，原版更容易做小幅精确贴近；需要你上手机确认是否接受这种"载具感"。

## 2. 加速反馈

**实现参数**
- 触发：右下「冲刺」按住，或第二指按住屏幕任意处
- Boost 槽：100 上限，消耗 46/s（满槽约 2.17 s），停用 0.45 s 后以 17/s 回充
- 速度倍率：1.55–1.80×（按鲨鱼），加速度 78 m/s²
- 视觉：FOV 52°→58°，相机后拉 1.6，尾部气泡，屏幕放射速度线（CSS overlay）
- 音频：带通噪声 300→1800 Hz，350 ms

**与原版差异**
- 原版冲刺是"点击触发一次冲刺"，本项目是"按住持续冲刺 + 槽耗尽"，**持续感更强、爆发感略弱**。
- 原版有冲刺条；本项目用右下圆形按钮 + 环形进度，HUD 位置不同但信息等价。
- 本项目加入速度线与 FOV 变化，**加速的视觉反馈比原版更明显**；音频为程序化合成，音色不等于原版。

## 3. 镜头跟随

**实现参数**
- 透视 52°，默认 z=18，位于鲨鱼后上方
- 位置弹簧 5.2/s（约 63% 在 190 ms，95% 在 580 ms）
- 前视偏移 = 速度×0.36，限幅 ±6 m；垂直 = 速度×0.12，限幅 ±2 m
- 冲刺时 z+1.6；Boss 战自动拉远至 z=38 并居中双方
- 受击/爆炸震屏，2.4/s 衰减

**与原版差异**
- 原版是全 3D 尾随，镜头会随鲨鱼 3D 朝向变化；本项目锁定侧视平面，**镜头更稳、更可预测，但缺少空间感**。
- 原版在快速下潜/上浮时镜头俯仰更明显；本项目垂直跟随被限幅到 ±2 m，**大幅下潜时主体会更靠画面边缘**。
- 本项目在 Boss 战有专门的拉远构图，原版 Boss 房更接近近景压迫感。

## 4. 延迟预算（设计值）

| 环节 | 目标 | 实现 |
|---|---|---|
| 触摸 → 摇杆方向 | ≤1 帧 | Pointer Events 同帧更新 |
| 冲刺按下 → 速度变化 | ≤1 帧 | 同帧读取 boost 状态 |
| 镜头响应 63% | ≤200 ms | 190 ms |
| 暂停/任务面板 | ≤50 ms | DOM 同步切换 |
| 死亡 → 结算面板 | ≤1 帧 | 事件触发即切换 |
