# GDD — 经典版《饥饿鲨》移动端 Web 复刻（MVP）

> 依据 `docs/research.md`。目标：手机浏览器横屏直开，5 分钟内形成"出生→吃→变大→金潮→任务→死亡→复活"闭环。
> 命名一律使用原创占位名（如 "Reef Shark / Mako" 等真实物种名可用，不使用原版 Logo、字体、角色专名与 UI 切图）。

## 1. 范围界定

### 1.1 必做（MVP）

| 系统 | 实现标准 |
|---|---|
| 游动/转向 | 动态虚拟摇杆，2.5D 平面（x 水平 / y 深度），带惯性与转向阻尼 |
| 冲刺 | 独立 Boost 按钮 + 第二指点击，槽耗尽后延迟回充 |
| 生存 | 饥饿持续掉血，进食回血；受伤来源 5 种 |
| 捕食 | 接触自动撕咬，按猎物体型/血量计算咬合时长 |
| 成长 | 跨局等级 1→10（经验存档）+ 局内体型增长，等级作为解锁门槛 |
| 分数 | 连吃倍率 2x→24x，断连衰减；结算最高分 |
| 金币 | 金色猎物 + 金潮 + 任务 + 生存奖励 + 沉没物 |
| 金潮 | 进度条满触发 20s：全猎物变金、回满血、无敌、无限冲刺 |
| 任务 | 每鲨 4 条 + 1 条超级任务；奖励金币/经验 |
| 鲨鱼 | 6 条：Reef / Mako / Hammerhead / Tiger / Great White / Megalodon |
| 地图 | 单张 900m × 150m 主地图，4 个深度分区 + 螃蟹巢 |
| Boss | Giant Crab，3 阶段，闪避→弱点→冲刺攻击 |
| 死亡/复活 | 结算；每局 1 次免费复活（50% 血），之后 300 金币 |
| 存档 | localStorage：金币、已解锁鲨鱼、升级、最高分、任务进度 |
| UI/音频 | 手绘漫画风 HUD；Web Audio 程序化 BGM 与音效 |

### 1.2 明确砍掉（不占位、不伪装）

- 多地图（北极/南海等）、倾斜控制、陀螺仪校准
- 内购/广告/宝石经济（宝石仅作为 Boss 奖励展示）
- 特殊鲨鱼、进化形态、Baby Shark、皮肤、配饰（激光/喷气背包/礼帽）
- 每日宝箱、7 日签到、在线排行榜、live-ops 活动
- 游泳以外的陆地爬行、传送门等后期能力
- 贝壳解锁任务流程（降级：任务常驻可查看，贝壳仅作金币收集物）
- 15 件沉没物 → **降级为 8 件**

### 1.3 兼容/降级说明

- 低端机自动降 DPR（2.0→1.25）、关闭光柱与焦散。
- iOS Safari 首次触摸解锁音频；切后台暂停并静音，回前台恢复。

## 2. 操作映射（动态摇杆方案）

| 输入 | 行为 | 反馈延迟 | 参数 |
|---|---|---|---|
| 单指按下屏幕任意处（避开按钮） | 在该点生成摇杆，原点=触点 | ≤16ms | 外圈 64px，死区 8px，最大位移 56px |
| 单指拖动 | 方向 = 触点-原点归一化；力度 = 位移/56 | 每帧 | 摇杆透明度 0.35，按下 120ms 淡入 |
| 单指抬起 | 摇杆淡出，鲨鱼按阻尼减速 | 0.35s | 减速度 18 m/s² |
| 第二指轻点屏幕 | 冲刺（按住持续） | ≤16ms | 与右侧按钮等价 |
| 右下 Boost 按钮 | 冲刺（按住持续） | ≤16ms | 直径 88px，安全区内缩 16px |
| 右上暂停 | 暂停/继续/设置 | ≤50ms | 44px 触控热区 |
| 屏幕旋转 | 竖屏显示"请横屏"遮罩 | — | 不进入游戏 |
| 首次任意触摸 | 解锁 AudioContext | 立即 | 失败则下次触摸重试 |

- 摇杆位置完全动态，无固定底盘；左右手均可。
- 禁止双击缩放、长按菜单、页面滚动回弹、下拉刷新。
- 冲刺优先级高于摇杆，不改变朝向，仅沿当前朝向加速。

### 3.5 金潮 / 倍率 / 经济

- 倍率：每次进食 +0.25x，1.2s 未进食 -0.5x；区间 2x–24x。
- 金潮进度：每 100 分 +1%，满 100% 触发；持续 20s；期间猎物全金、回满血、无敌、冲刺不耗槽。
- 单局金币预期：新手 150–400；熟练 600–1,500。
- 生存奖励：每分钟 +20/40/70/110/160…（递增 30）。
- 任务奖励：普通 150–400；超级任务 1,500。
- 复活：首死免费（50% 血）；之后 300 金币/次，每局最多 2 次。

## 8. 技术方案

- **栈**：Vite + TypeScript + Three.js（WebGL2），无框架、无状态库。
- **渲染**：PerspectiveCamera；`scene.fog` 指数雾 + 渐变穹顶 ShaderMaterial；光柱/焦散为自定义 shader；InstancedMesh 鱼群；Points 粒子。
- **物理**：圆-圆碰撞 + 按 X 轴空间哈希（cell 8m）；无物理引擎。
- **状态**：单一 `GameState` + `EventBus`（发布/订阅）；UI 只读快照。
- **循环**：`requestAnimationFrame`，dt 上限 1/30；固定 60Hz 逻辑步进；无每帧分配（预分配 Vector3/对象池）。
- **音频**：Web Audio 合成，首次 pointerdown 解锁；`visibilitychange` 暂停。
- **存档**：`localStorage["hse-lite-v1"]`，JSON，版本号迁移。
- **性能红线**：Draw call ≤70；三角形 ≤120k；实体 ≤140；gzip 首屏 <1MB（红线 5MB）；低帧自动降 DPR。
- **适配**：横屏锁定提示、`viewport-fit=cover`、安全区 CSS 变量、Pointer Events、`touch-action:none`。
